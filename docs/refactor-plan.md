# 重构计划与边界

本文件约束 1.0.2 统计链路重构的范围。行为正确性优先于代码形式。

## 分阶段

1. 冻结行为基线和性能基线。
2. 拆分 parser 事件处理，不改变事件顺序。
3. 拆分轮次建立、记录归属和计时聚合。
4. 单独优化热路径和内存分配。
5. 运行单元、实机、PowerShell 和五副本校验。

## 必须保持

- `requestCount`、`sessionTotal`、当前轮累计和缓存命中口径不变。
- 轮次来源优先级不变：`turn_context` → `turn_id` → `user_message` → 单轮。
- modern / legacy 混合、回声、replay、unique、重置、截断、乱序和分片行为不变。
- 页面协议 schema v3、签名负载和隐私字段不变。
- 请求和轮次的对外上限仍为 500。
- `retainRequests=false` 时最近 500 条明细的顺序和语义不变。

## 禁止

- 不用单调递增假设处理累计值。
- 不用时间戳充当跨格式唯一身份。
- 不在重构提交中夹带协议或 Bug 修复。
- 不以修改测试期望值来适配实现变化。
- 不在统计热路径引入大数组复制或重复全量遍历。

## 验收

- `npm run check`
- `npm test`
- 固定 fixture 全输出快照
- 20k / 100k 性能基线
- `verify-live`
- Playwright 实机测试
- 源码、部署、cache、用户脚本和安装 ZIP 哈希一致

旧版本与 1.0.2 的逐 fixture 回溯 diff 已明确延后，不由本阶段自动执行。
