# 性能基线

本文件记录本地合成基准，用于比较同一台机器上的改前/改后结果。

## 当前原组件模式实测

2026-11-01 在 Windows 11 当前开发机观测：

| 进程 | 工作集 | 私有提交 |
| --- | ---: | ---: |
| PowerShell watchdog | 约 90–120 MB | 约 90–100 MB |
| Node monitor | 约 140–160 MB | 约 140–160 MB |

合计约 230–280 MB，空闲 CPU 采样接近 0%。该值是原组件模式观测值，不是 Rust
launcher 的预测值，也不是跨设备 SLA。详细说明见 `docs/context-and-resources.md`。

`rust-launcher/` 0.1.0 Alpha 在独立计划任务和模拟 Node 夹具中测得 supervisor
工作集约 6.8–6.9 MB，3 秒采样低于 0.001% 单核显示精度。该数字只代表 Rust 启动层，
不包含真实 Node；它不是正式默认模式，也不是跨设备 SLA。

## 命令

```powershell
npm run perf
npm run perf -- 100000
```

基准脚本生成单个会话和一个长轮次，逐条追加 usage 记录，不计入真实消息正文。

## 1.0.2 对照

环境：Windows、Node.js 24、单次进程，本地临时目录。

| 记录数 | 指标 | 1.0.1 中位数（3 次） | 1.0.2 中位数（5 次） |
| ---: | --- | ---: | ---: |
| 20,000 | 首次统计 | 51.1 ms | 39.6 ms |
| 20,000 | 追加一条后统计 | 50.2 ms | 32.2 ms |
| 100,000 | 首次统计 | 222.1 ms | 191.3 ms |
| 100,000 | 追加一条后统计 | 213.1 ms | 180.4 ms |

1.0.2 的主要收益：

- 请求明细使用固定 500 条环形缓冲，移除逐条 `shift()`。
- 会话速度与稳健速度样本合并进已有记录遍历。
- 删除记录和轮次的反转副本。
- 删除不必要的临时过滤数组。

## 解释边界

- 数值只用于本机相对比较，不是跨设备绝对 SLA。
- 堆增量会受 GC 和测试输入数组影响，单次结果不作为硬门禁。
- 代码重构后的硬门槛是同机同规模不得慢于基线 5%。
- 较大算法改动应至少运行 3 次并取中位数；正式发布建议运行 5 次。
- 统计结果必须与重构前逐字段一致，性能改善不能以口径变化为代价。
